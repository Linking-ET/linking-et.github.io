# 绑定群机器人

## 绑定方法

> [!info]Java正版/离线通用

- 登录之后在聊天栏输入指令 /easybot bind ，查看命令回应中要求输入的验证码

- 在[LinKing-ET 万物互联 服务器总群](https://qm.qq.com/q/IUc78m41yY)发送"绑定 验证码"即可绑定成功

- 动图示例：

![绑定示例](/res/img/guide/bot/easybot_bind.webp =500x500)

> [!info]可以通过在群内发送“我的绑定”查询自己的绑定信息

> [!caution]不可重复绑定
> 群内发送“解绑”消息可以解除自己的绑定
